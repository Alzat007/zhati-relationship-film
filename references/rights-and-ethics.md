# 片源、肖像、声音与伦理

本片是“关系议题的影像随笔”，不是心理诊断，也不是真实案例。视觉素材必须可追溯，观点必须留有余地。

## 电影 / 视频 / 照片素材

素材可以来自客户实拍、公版电影、授权 stock、照片/档案、纯文字。**没有哪一种来源是必须的。**

### 参考实现（不是必须）

- 《第七天堂》7th Heaven (1927)，导演 Frank Borzage。
- 来源：Wikimedia Commons `File:7th Heaven (1927).webm`。
- 页面标注美国公版；区域表将中国列为公版，同时注明欧盟、英国等地区期限不同。**不能写成“全球公版”。**
- 只取室内男女相处片段；去除原片全部音轨；不加速、不篡改人物。
- 如果使用本片，成片角标与片尾保留：“电影画面《第七天堂》1927 · 非真实案例”。
- 客户不需要电影时，不要为了系列感硬塞；换成客户素材/照片/纯文字。

### 客户实拍 / 客户照片

- 取得书面使用授权；确认平台、地区、时长、是否可二创。
- 人脸、声音、未成年人、聊天记录、医疗/心理内容要单独确认；必要时打码/变声。
- 不泄露客户未公开的产品、数据、门店信息。
- 画面标“客户提供”/品牌名；片尾来源栏写清。
- 不要把客户故事改写成诊断或因果断言。

### 授权 stock

- 保留 license/订单号/作者；确认覆盖发布平台与地区。
- 不用带水印的预览；不把 stock 说成客户实拍。
- 片尾/来源记录写清平台、作者、license。

### 多来源

- 一期最多 2–3 种来源；每个来源单独 credit。
- 统一 grade/字/字幕；不要一段黑白、一段高饱和彩色。
- 不要把多部版权片剪成“经典爱情混剪”。

### 选新片源时

优先：
- 1931 年之前在美国发表、且来源页明确标注 Public Domain 的作品。
- Wikimedia Commons / Internet Archive 上有明确权利说明的版本。
- 只取原始电影画面，避开现代修复版新增的片头、字幕卡、配乐、标识。

必须：
- 保存来源页快照/URL、下载日期、片名、年份、导演、使用的原片时码。
- 去除原片音轨；不要用电影原声。
- 在画面里标注片名/年份/“非真实案例”。
- 发布前按发布地区复核；不同地区状态可能不同。

不要：
- 用《卡萨布兰卡》《罗马假日》《花样年华》等仍受版权保护的片段，除非用户提供明确授权。
- 用“经典爱情混剪”名义把多部版权片剪在一起。
- 把电影角色当成真实心理案例，或用演员表情给真人下诊断。

## 声音

- 旁白：用户此前授权的本人声线，本地生成；不上传参考录音。使用 `macos-local-voice` skill 的本地工作室。
- 如果用户没有可用声音：明确问“本人录音 / 本地克隆 / 系统音色 / 无声”，不要擅自用云服务克隆。
- 音乐：原创合成/授权素材；不要用版权歌曲。母版的配乐只属于母版，新一期重新做。
- 雨声/环境声：可合成；保持低电平，不要盖过旁白。
- 电影原音轨一律弃用。

## 伦理底线

必须保留的限定（可按本期措辞调整，但意思要在）：
- “一种理解角度”
- “这不是对所有人的解释”
- “伤害的责任，不能用潜意识或童年来替对方开脱”
- “解释视角，不是诊断”

不要：
- 诊断任何人（NPD、依恋类型、创伤后应激等）或给观众贴“吸渣体质”“恋爱脑”标签。
- 说“你潜意识里选择了被伤害”“你童年决定了你会遇到谁”这类因果断言。
- 把电影片段当真实案例，或用演员表情证明心理学结论。
- 伪造哲学家原话；不要给释义加引号冒充名言。
- 把“善良”包装成“必须无限度忍受”。

## 画面上的标识（按本期素材写）

- 右下角：用了电影 → `电影画面《[片名]》[年份] · 非真实案例`；用了客户素材 → `画面由客户提供` 或品牌名；纯文字 → 可不标，但来源记录要写。
- 思想家/专家段：`解释视角，不是诊断` 印章（如果本期有心理/思想视角）。
- 片尾：`画面仅作情绪与关系意象，非真实案例，也不构成心理诊断。不同地区的素材权利状态可能不同。`
- 片尾来源栏：文稿/旁白、画面（电影/客户/stock/照片）、肖像；每类写清作者/年份/license。
