# 客户 brief：内容随要求变

固定的是**做法**，不是**素材**。每一期的主题、文案、电影/实拍/照片、人物、配色、旁白、音乐、封面和发布文案，都由客户 brief 决定；母版的《第七天堂》只是参考实现。

## 只问会改变结果的 8 个问题

一次问完，每个问题都给默认值，客户可以逐条改：

1. **客户/品牌与受众**：谁在看？年龄、性别、城市、关系阶段、对“关系”的默认态度。
2. **平台与时长**：视频号 / 小红书 / 抖音 / B站 / 公众号；2:40–3:40，还是 60–90 秒？
3. **语气**：克制散文 / 第一人称故事 / 学术解释 / 品牌口吻 / 轻幽默。默认克制散文。
4. **必须使用 / 禁止使用的素材**：客户实拍、产品、门店、用户故事、某部片的片段、某位专家肖像；有没有不能出现的人、品牌、词。
5. **素材权利**：客户自有 / 已授权 stock / 公版 / 需要我们用 AI 找免费 stock。没有书面授权的版权片，不用。允许找 stock 时，预算/来源/是否必须可商用？
6. **必须说 / 不能说**：品牌 claim、法务限制、不能承诺的效果、不能做的诊断。
7. **声音与音乐**：本人录音 / 本地克隆 / 系统音色 / 无声；音乐是原创、客户提供、还是授权曲库。
8. **交付**：横屏 16:9 正片 + 3:4 封面？要不要 SRT、竖版、不同平台剪辑、发布时间。

## 客户要求 → 内容/素材矩阵

| 客户类型 | 叙事重点 | 推荐素材模式 | 视觉处理 | 封面 |
|---|---|---|---|---|
| 情感博主 / 小红书 | 第一人称、具体场景、两个自省问题 | 客户日常实拍 + 一点公版胶片纹理 | 暖灰/低饱和，保留人脸真实质感 | 问题式标题 + 一句金句 |
| 视频号 / 30+ 情感号 | 故事 + 一个思想视角 + 可执行建议 | 公版电影 + 1–2 张公版肖像 | 黑白电影 + 宋体，暗底 | 大标题 + 伞/物件 |
| 品牌 / 产品 | 用户故事，产品作为“关系中的物” | 客户产品/门店素材 + 授权 stock | 品牌色只做强调，别把产品做成广告 | 产品 + 一句关系洞察 |
| 影评 / 文化号 | 影史案例、2–3 部片对照 | 多部公版电影 | 统一黑白/颗粒，逐片标注 | 片名/年份 + 问题 |
| 无素材 / 纯文字 | 观点、信、独白 | 纯文字 + 一个图形物件 | 纸/墨/排版，不硬塞电影 | 大字 + 极简符号 |
| 企业/机构 | 员工/客户故事、边界与尊重 | 客户访谈/实拍 + 公版建筑/纹理 | 真实人物优先，少滤镜 | 人物 + 一句话 |

## 把 brief 变成一页内容计划

在写旁白前，先写这 10 行：

```
受众：
平台/时长：
一句话主题：
钩子问题：
两个概念：
思想/心理视角（可空）：
伦理转折：
一句很小的话：
必须出现/不能出现：
素材模式与来源：
```

这 10 行客户确认后，再写 950–1150 字旁白。不要先写满 3 分钟再问客户要素材。

## 三个确认点

1. **Brief 确认**：上面 10 行 + 素材权利。
2. **First still 确认**：钩子/封面/一个关键场景的静帧；客户确认“这是我要的感觉”再全量做。
3. **Final 确认**：成片 + 字幕 + 封面 + 来源；不要在没看片的情况下直接发布。

## 客户改需求时

- 改**文案**：重写旁白 → 重新生成 cues → 重排时间；不要只换字幕。
- 改**素材**：换 `data-asset-slot` 对应文件 → 重算视频窗口 → 换静帧/credit；不要只换背景不换字幕里的“电影画面”标注。
- 改**时长**：优先删/并段落，不要整体加速；不要把 3 分钟硬压成 60 秒还保留全部论点。
- 改**平台**：16:9 是母版；3:4 是封面；9:16 正片要重新布局，不能裁。
