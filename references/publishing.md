# 发布文案

先看成片，再写文案。文案要跟这一期的具体句子走，不要复用上一期。

## 标题

问句优先，短、具体、有钩子。备选公式：

- 为什么有些好人，会和错的人交往？
- 为什么我们总在关系里，证明自己值得被爱？
- 你不是不够好，只是把伞全倾向了对方
- 好的关系，不该只有一个人在努力
- 一个人再努力，也撑不起两个人的关系
- 如果你总在等对方“发现”，这支片子给你

不要用“吸渣体质”“恋爱脑”“NPD”这类诊断式标题。

## 长文案（视频号 / 小红书，280–450 字）

结构：
1. 一个具体场景（雨/伞/一句话），不要先讲道理；
2. 一个概念区分（A 是……，B 是……）；
3. 一个思想视角（“有人在讨论……时强调……”）；
4. 一个限定（“这不是说……”）；
5. 两个自省问题；
6. 一句可执行的小话；
7. 收束 + 来源/标签。

模板：

```
[具体场景，1–2 句]

[概念 A] 是[……]；
[概念 B] 是[……]。
这不是同一道题。

[思想家/视角] 提醒我们：[一句释义，不要加引号冒充原话]。
但这不是说，[需要排除的误读]。
[必要的限定：欺骗/改变/相处后才看见/责任在伤害者]。

所以，[自省的目的，不是责怪自己]：
[问题 1]？
[问题 2]？

[第二视角/自我尊重]。
[两句“不意味着”的边界]。

改变可以从一句很小的话开始：
“[本期的小句子]。”

[收束句：保留温柔，也给自己留位置。]

🎬 影片画面：[片名] [年份]（公版）
#亲密关系 #爱情观 #自我成长 #情感文案
```

## 短文案（抖音/快手/视频号，60–100 字）

```
[钩子问题]

因为 [A] 是[……]，
[B] 是[……]。

[一句结论]。

“[本期的小句子]。”

[一句收束]。
#亲密关系 #爱情观 #情感
```

## B站/公众号简介

标题：
`[钩子问题] | 3分钟关系影像随笔`

简介：
```
这支[时长]的影像随笔，从[具体物]讲起：[本期的 3–4 个核心问题]。
涉及[思想家/视角]，但不对任何人做心理诊断。
电影画面来自公版经典爱情片《[片名]》（[年份]）。
```

时间轴（按本期实际改）：
```
00:00 [钩子]
00:3x [概念区分]
01:0x [心理视角]
01:4x [伦理转折]
02:1x [自我尊重]
03:0x [一句小话]
```

## 置顶评论

二选一：
- “你可以继续温柔，但不用再用淋湿自己来证明爱。”
- “你上一次在关系里说‘我也需要这把伞’，是什么时候？”

## 标签

固定：#亲密关系 #爱情观 #自我成长
按本期加 2–3 个：#善良与边界 #情感文案 #关系模式 #自我尊重 #经典电影

## 封面字

- 主标题：本期问句（3:4 封面用两行）
- 副钩子：一句金句（≤16 字）
- 角标：`电影画面《[片名]》[年份] · 非真实案例`

## 平台差异

- 视频号：偏故事、偏口语，长文案可以 350–450 字。
- 小红书：第一人称、短段落、可加“建议收藏”，标签 8–12 个。
- 抖音/快手：前 3 秒钩子最重要，文案 60–100 字。
- B站：标题可以更长，简介写清结构、来源、时间轴。
