# 视觉系统

## 色板

| 角色 | 值 | 用法 |
|---|---|---|
| 放映机黑 | `#0b0907` | 底、黑场、片尾 |
| 银幕米白 | `#efe6d6` | 主文字、伞线、字幕 |
| 暖琥珀 | `#c9955a` | 关键词、时间、重点句、封面“错的人” |
| 旧胶片灰 | `#a59a89` | 次级文字、出处 |
| 警示酒红 | `#8e3f32` | 全片 ≤3 次：划线、“不是。” |
| 雨灰蓝 | `rgba(150,174,181,.5)` | 雨、湿肩，不要变成蓝紫 |

不要用蓝紫渐变、霓虹青紫、深紫星空。整片同一套色，封面也只用这套。

## 字体

## 素材来源是变量

固定的是**怎么看**：黑白/暖灰、胶片颗粒、宋体大字、底部字幕、暗角。素材可以是公版电影、客户实拍、授权 stock、照片、纯文字、混合。

- **客户实拍**：优先真实；人脸保持自然，不要把客户修成电影剧照；产品只做“关系中的物”，不要硬广。
- **公版电影**：可以有时代感；去音轨、补帧、逐片 credit。
- **授权 stock**：留 license；不要水印预览。
- **照片/档案/肖像**：标明照片/雕像/绘画；公版或授权。
- **纯文字**：没有 footage 时，让字/留白/一个物件撑画面。
- **混合**：最多 2–3 种来源；一套 grade、一套字、每源 credit。

## 版式（1920×1080）

- 左侧文字安全区：`x=132px`，宽 `720–940px`。
- 大标题：`118px`，行高 1.16；问题/金句：`54–92px`；正文：`38–48px`。
- 字幕：底部 `50px`，宽 1500px，居中，28px；下方留 `#subveil` 渐变。
- 右下角来源：13px，`rgba(239,230,214,.46)`。
- 不要加固定页眉、页码、页框。母版只保留顶部小签和底部来源。

## 影像底

母版的《第七天堂》只是参考实现；新一期可以换客户实拍/公版/stock/照片/纯文字。

- 参考片源（仅 demo）：《第七天堂》7th Heaven (1927)，582×480，24fps，已去音轨、补到整数帧。
- 电影/老照片基础滤镜：`grayscale(1) contrast(1.12) brightness(.74) sepia(.10)`。
- 文字密集段：`blur(3–4px) brightness(.5–.65)`，让字是主角。
- 客户实拍：不要默认黑白；先做轻调色（对比/饱和/温度），人脸保持真实；如果品牌要求统一，再用同色系 LUT/曲线。
- 产品/门店：作为卡片/侧栏/背景局部，不要满屏硬广；保留 logo 可读性。
- 每段用 `data-start` / `data-duration` / `data-media-start` / `data-playback-rate` 排窗口；确保淡出前不会先播完。
- 一个来源最省事，但**不是硬性要求**；2–3 个来源也可以，只要统一 grade/字/字幕，并逐源 credit。

## 伞/雨（默认隐喻，不是唯一）

伞/雨是母版的默认物；客户要别的物（门/车票/手机/碗/钥匙）时，换 SVG/画面，不要还留着伞的文案。换隐喻时保留“具体物—动作—变化—收束”的 3–4 拍。

- SVG `viewBox="0 0 1000 800"`；伞心 `(500,230)`，柄 `(500,560)`，两个人 `(330,280)` 与 `(650,300)`。
- 伞盖是**线 + 半透明深色填充**：`fill rgba(10,9,8,.86)`，`stroke rgba(239,230,214,.92)`，`stroke-width 3.4`。
- 倾斜围绕 `500px 560px` 旋转；向右 7–8° 表示“倾向对方”，结尾回到 0–2°。
- 左人（撑伞者）持伞；湿肩是低透明度灰蓝块 + 3 条滴线；不要把湿肩画成一个大灰包。
- 右人（对方）先远一点（x +40），到“愿意一起调整”时回到 0。
- 雨是 canvas：约 150 条斜线，alpha .1–.5；雨量随段落变化，结尾变轻。
- 伞盖边缘/人物轮廓可以有一圈极淡的米白描边，避免在暗底上糊掉。

## 镜头与动效

- 文字：遮罩上移（`yPercent:110 → 0`），`expo.out`，每行 stagger .2–.4s；不要逐字弹跳。
- 胶片：每个 clip 从 1.04 缓推到 1.10–1.17，`ease:'none'`；一个镜头内只做一次。
- 转场：硬切只给伦理转折；其余用 0.6–1.0s 的淡化/黑场 + 胶片颗粒承接。
- 闪白：`#flash` 0.1s 起、0.55s 落；只在 100.4s 附近用一次。
- 酒红划线：`#turnStrike` 从 0 到 1，0.55s；`#turnNot` 用 180px 宋体盖上去。
- 全片不要每镜同一方向推近；推、拉、横移、停要交替。

## 声音

- 母版 `assets/score.wav` 是旁白＋配乐＋雨声的成品混音。新一期必须替换。
- 目标：约 −15 LUFS，真峰值 ≤ −1.5 dBFS；旁白比音乐高约 12–15 LU。
- 页面用 `<audio id="score">`，不是 `om-sound`；渲染必须加 `--silent`，否则 `om render` 会尝试重建音轨。
- 如果改用 `om voice` + `om sound` 的管线，把 `id` 改成 `om-sound`，并按 huashu-motion 的正常渲染命令走；不要两套混用。

## 3:4 封面

- 1080×1440。
- 顶部：`ON KINDNESS & LOVE` + 中文小标 + 时长。
- 标题：84px 宋体，两行；“错的人”用琥珀色。
- 中部：伞 + 两个人；伞在标题下方，不要压字。
- 底部：一句金句（34–36px），再下一行来源。
- 背景：电影静帧 / 客户照片 / 品牌纹理；`blur(2–3px) brightness(.4)`，只做纹理，不抢主体。
- 源文件：`cover/cover.html`。
