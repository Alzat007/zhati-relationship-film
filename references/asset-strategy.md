# 素材策略：一份模板，多种素材

## 核心

固定：
- 16 拍叙事语法；
- 字体/色板/运动/声音的质量标准；
- 3:4 封面；
- 来源、伦理、QA 硬门。

可变：
- 文案、旁白、音乐；
- 电影片段、客户实拍、产品/门店、照片、授权 stock；
- 人物肖像 / 专家 / 素人；
- 配色（品牌色只做强调，不换掉整套视觉 DNA）；
- 封面背景与发布文案。

**不要因为母版用了《第七天堂》、弗洛伊德、亚里士多德、康德，就每一期都硬塞这些。** 客户不需要时，换成客户素材、别的公版人物、或纯文字。

## 五种素材模式

### A. 客户实拍 / 照片（优先）

适合：品牌、门店、用户故事、真实关系场景、产品作为“关系中的物”。

做法：
- 先看素材，按 16 拍选“能承担画面事件”的镜头，不要拿素材硬凑字。
- 人脸不要过度磨皮/换脸；保留真实质感。客户素材的调色以“统一”为目标，不是把每段都调成电影。
- 竖屏素材放成“卡片”或侧栏，不要强行拉成 16:9 满屏。
- 写清授权/肖像同意；画面标“客户提供”或品牌名。
- 不要把客户产品做成硬广；产品只作为关系隐喻里的一个物。

### B. 公版经典电影

适合：时代感、雨/夜/火车站/房间等情绪底；影评/文化号。

做法：
- 1931 年前美国发表、来源页明确 Public Domain 的片；或 Commons/Internet Archive 明确标注的版本。
- 只取原始电影画面，避开现代修复新增片头/字幕/配乐。
- 去原音轨；补到整数帧；标注片名/年份/“非真实案例”。
- 一部片可以贯穿，也可以 2–3 部片按段落切换；每部片都要单独 credit。

### C. 授权 stock / AI 联网找的免费 stock

适合：缺具体场景、需要城市/雨/手/门/车站等通用镜头。

做法：
- 客户没有素材时，AI 可以先搜 3–6 个候选（Mixkit/Coverr/Pexels/Pixabay/Commons），给客户看页面 + license + 缩略图；确认后再下载。
- 用 `scripts/stock_search.py` 搜，`scripts/fetch_stock.py` 下载/去音轨/标准化/写 manifest。
- 保留 license 证明/订单号/页面；不要用带水印的预览；不要从 YouTube/B站/流媒体/版权片扒。
- 授权范围要覆盖平台/地区/时长；不确定就问客户。
- 统一调色；在来源记录里写清平台/作者/license。
- 详细规则见 `references/stock-sources.md`。

### D. 公版肖像 / 档案照片

适合：思想家、专家、历史人物、旧报纸、手稿。

做法：
- 标明“照片/雕像/绘画”，不要混。
- 公版来源 + 作者/年代/摄影者；不要 AI 生成冒充历史人物。
- 没有合适肖像时，用文字卡/书名/手稿，不要硬找一张“看起来像”的脸。

### E. 纯文字 / 图形

适合：没有素材、或客户要求极简；也适合作为全片的“呼吸段”。

做法：
- 让字成为画面：大字、留白、细线、纸/墨/胶片颗粒。
- 不要用 emoji 拼画面；不要用 AI 味的蓝紫渐变。
- 一个物件（伞/门/车票/碗/手机）就可以撑起 3–4 拍；不需要每拍都有 footage。

### F. 混合（默认推荐）

一期最多 2–3 种来源，例如：
- 客户实拍（主）+ 公版电影（纹理/转场）+ 公版肖像（观点段）；
- 公版电影（主）+ 客户产品（1–2 个特写）；
- 照片/档案（主）+ 纯文字（转折段）。

统一方法：
- 一套调色（黑白/暖灰/品牌单色），一套字体，一套字幕样式，一套颗粒/暗角。
- 不同来源之间用“同一物件/同一颜色/同一构图”承接，不要每段换一种画风。
- 每个来源单独 credit；片尾来源栏可以列 2–4 行。

## 模板里的素材槽

`index.html` 里的视频/图片带 `data-asset-slot`，对应关系：

| slot | 位置 | 默认用途 |
|---|---|---|
| `clip_01`–`clip_11` | 11 个全屏/背景视频 | 钩子、故事、区分、视角、冷场、责任、练习、结尾 |
| `mirror_clip` | 镜面里的视频 | 自省/倒影 |
| `still_man` / `still_woman` / `still_couple` | 区分帧、循环卡、镜面鬼影 | 人物/关系静帧 |
| `still_room` / `still_hands` | 备用静帧 | 空间/手部细节 |
| `portrait_aristotle` / `portrait_freud` / `portrait_kant` | 三个肖像段 | 思想家/专家 |
| `cover_bg` | 3:4 封面背景 | 电影/客户照片/纹理 |

替换步骤：
1. 把客户/新素材放进 `assets/imported/`，按 slot 命名，或保留原名。
2. 填 `assets.manifest.json`（来源、权利、credit、scenes）。
3. 改 `index.html` / `cover/cover.html` 里对应 slot 的 `src`。
4. 用 `ffprobe` 看时长，重算 `data-start` / `data-duration` / `data-media-start` / `data-playback-rate`。
5. 需要静态图时用 `prepare_media.sh` 或 ffmpeg 抽帧。
6. 改右下角 `#credit`、片尾 `#credits .cols` 和 `素材来源.md`。
7. `python3 scripts/asset_report.py --manifest assets.manifest.json --project .` 检查缺文件/缺 credit。

## 素材 manifest

`templates/assets.manifest.example.json` 是模板。最少字段：

```json
{
  "slot": "clip_01",
  "type": "client_video",
  "path": "assets/imported/client_a.mp4",
  "source": "客户提供",
  "rights": "client-owned",
  "credit": "客户提供",
  "media_start": 0,
  "duration": 8,
  "scenes": ["hook", "umbrella"]
}
```

`asset_report.py` 会检查：
- slot 是否重复；
- 文件是否存在；
- `rights` / `credit` / `scenes` 是否为空；
- 视频能否 probe 到时长。

## 多源统一：三条硬规则

1. **一个 grade**：全片同一套黑白/暖灰/品牌单色；客户人脸保持自然，不要一会黑白一会彩色高饱和。
2. **一套字**：宋体大字 + 苹方字幕 + EB Garamond 小签；不要每段换字体。
3. **每源有 credit**：片名/年份、客户名、stock 作者/license、肖像作者/年代；片尾至少列 2–4 行。

## 隐喻也可以换

伞/雨是母版的默认物，不是唯一物。可以换成：
- 门（谁进谁出）、车票（谁在等）、手机（谁先回）、碗（谁洗碗）、钥匙（谁有权限）、一条围巾/一件外套。

换隐喻时：
- 仍然只用一个主物，贯穿 3–4 拍；
- 保留“具体故事 → 概念区分 → 自省”的功能；
- 改封面和片尾，不要还留着伞的文案；
- 如果客户要“完全没有隐喻”，就走纯文字/档案模式，不要硬塞物件。

## 人物与思想家

- 不是每期都要弗洛伊德/亚里士多德/康德。客户有专家/创始人/用户时，用他们的真实肖像/访谈；没有就只用文字和书名。
- 任何人物出现都要有来源和身份标注；不要把演员/客户/素人写成“心理学家”。
- 不要伪造引语；用“他讨论过/一种理解角度/这本书里有一个说法”。

## 客户素材的边界

- 书面授权/使用范围；人脸、声音、未成年人、医疗/心理内容要额外确认。
- 不泄露客户未公开的产品、数据、聊天记录；打码/授权。
- 不把客户故事改写成“诊断”，也不替客户下因果结论。
- 客户要求用版权片时：先要授权；没有就提供公版/stock/纯文字替代方案，不要先斩后奏。
